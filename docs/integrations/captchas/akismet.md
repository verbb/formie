# Akismet

Follow the below steps to connect Formie to the Akismet API.

### Step 1. Open the Captcha Settings
1. Navigate to **Formie** → **Settings** → **Captchas**.
1. Select **Akismet** in the left-hand sidebar.
1. Turn on **Enabled**.

### Step 2. Get your Akismet API Key
1. Go to [Akismet](https://akismet.com/) and create an account, or sign in to an existing one.
1. After signing up, Akismet will email you your API key. You can also find it in your Akismet account.
1. Copy the API key.

### Step 3. Connect Formie to Akismet
1. Paste the API key into the **API Key** field in Formie.
1. Save the captcha settings.

### Step 4. Form Setting
1. Go to the form you want to protect.
1. Enable **Akismet** for that form.
1. For multi-page forms, turn on **Show on All Pages** if the spam check should run on every page instead of only the final submit step.
1. Save the form.

Akismet screens submissions in the background, so there is no visible challenge on the front end.
