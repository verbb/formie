# @verbb/formie-vue

Vue bindings for Formie's server-rendered and client-rendered front-end packages.

## Install

```bash
npm install @verbb/formie-browser @verbb/formie-vue vue
```

## Usage

```ts
import { FormieForm, FormieClientForm, useFormieHtml } from '@verbb/formie-vue';
import '@verbb/formie-browser/css/formie.css';
```

## Public Surface

Use only the root package entry:

- `@verbb/formie-vue`

CSS continues to come from `@verbb/formie-browser`.
